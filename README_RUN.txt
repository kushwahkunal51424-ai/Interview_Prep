INTERVIEW PREP - COMPLETE PROJECT

Structure:
client/  -> React + Vite frontend
server/  -> Node + Express backend

1. Open terminal in server:
   cd server
   npm install
   npm run dev

2. Open another terminal in client:
   cd client
   npm install
   npm run dev

3. Frontend:
   http://localhost:5173

4. Backend:
   http://localhost:5000

The existing Dashboard and ProtectedRoute files are now connected in App.jsx,
so successful login can open /dashboard.

No node_modules folder is included; run npm install in both folders.
